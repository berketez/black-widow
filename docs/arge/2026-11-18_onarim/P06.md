## TIP-09 — yapısal algoritma etiketi

### Önce
Desenler gövdenin tamamında (dizgi ve tanımlayıcılar dahil), sözcük sınırı olmadan; çoğu anahtar sözcük; birçok algoritma tek eşleşmeyle. Örnekler (GT adıyla): `chmod`/`mkfifo`/`htop umask` → Galois (`mode`, `mode_t`); htop `Row_printTime` → Galois (`% 0x3c`); `tail usage` → PBKDF2 (yardım metnindeki "iterations"); openssl `print_verify_detail` → S-box (`"0123456789abcdef"[x & 0xf]`); tmux → anahtar çizelgesi (`thunk_FUN` içindeki "nk", IGNORECASE `Nk`); cksum `crc32_update_no_xor` → Base64 (Ghidra CRC tablosunu `"ABC…+/" + ofset` diye yazmış).

### Onarım (`karadul/reconstruction/c_algorithm_id.py`)
- Kural bloğu ve gerekçe `:531-` (dosya başı yorum), eşik `STRUCT_MIN_DISTINCT_KINDS = 2` (`:559`), `STRUCTURAL_PATTERNS` (`:574-`), `_code_only` / `_without_comments` / `_identifier_words` (`:777-`), `_scan_structural` (`:1429-`).
- Desenler **kod metninde** çalışır (dizgi/karakter sabiti boş sabite, yorum boşluğa; satırlar korunur). Dizgi içeriği yalnız `data_evidence`'ta ayırt edici veri olarak sayılır: base64 alfabesinin tamamı, **dizin olarak** kullanılırken (`"…+/"[x]`; `"…" + ofset` sayılmaz).
- Her desen adlandırılmış bir **kanıt türü**; etiket için en az iki farklı tür (`min_kinds`), `required` türlerin hepsi ve toplam `min_matches`. Tek yapısal eşleşmeyle etiket yok.
- Anahtar sözcük desenleri (`mod`, `iteration`, `rounds`, `ctr`, `affine`, `base64`, `match_len`, `huffman` …) kaldırıldı. `context_keywords` (Feistel, blok şifre kipi) kanıt değil, ek koşul: kod tanımlayıcılarının sözcüklerinde **tam sözcük** (`snake_case`/`camelCase` parçalanır; `background` ≠ `round`).
- Kanıt türleri algoritmanın gerçek biçimine bağlandı: Galois = GF(2ⁿ) indirgeme polinomu (`0x1b/0x11b/0x87/0xe1…`, zorunlu, tam belirteç) + yüksek bit + ikiyle çarpma (eski `* x % y` / `% 0x…` tamsayı modülü GF kanıtı değildi, kaldırıldı); hash turu = döndürme + seçim/çoğunluk (`~x & y`); S-box = bayt çıkaran tablo okuma + okumaların XOR'u (16'lık `& 0xf` tablosu sayılmaz); XOR şifreleme = yerinde tampon XOR'u + döngüsel anahtar indisi; modüler üs = modüler çarpım (zorunlu) + üs bit sınaması + yarılama (üçü); anahtar çizelgesi = gecikmeli XOR yinelemesi + bayt tablo okuma; PBKDF = XOR biriktirme + HMAC çağrısı; eliptik eğri = nokta toplama çağrısı + nokta çarpma/ikileme çağrısı; LZ = geri başvuru kopyası + çarpımsal karma; Huffman = kanonik kod yinelemesi + uzunluk histogramı; base64 = alfabe dizini (zorunlu) + 6 bit maske / kaydırma. Hiçbir desen silinmedi ya da kapatılmadı; her biri iki bağımsız biçim kanıtıyla etiket verebilir.

## TIP-08 — `@security` etiketi

### Önce
`_detect_security_relevance` adın küçük harfli hâlinde alt dize arıyordu; çağrı kanıtı yoktu, ad Karadul'un kendi önerisi de olabiliyordu. Gerçek çıktıda (yeniden oynatma = kayıt, 119/119): `RedisModuleCommandDispatcher`, `luaLdbLineHook`, `sqlite3session_patchset` → "Code injection/hooking mechanism"; `exprNewToken`, `getlogin` → "Handles authentication/credentials"; Redis `RM_ClusterCanonicalKeyNameInSlot`, `decodeTimeoutKey` → "Handles sensitive key material"; parametre metninde `key` → "Receives sensitive parameters".

### Onarım (`karadul/reconstruction/c_comment_generator.py`)
- Kurallar ve tablolar `:2071-` (`_SECURITY_CLASSES`, `_SECURITY_CALL_EXACT`, `_SECURITY_CALL_PREFIXES`, `_SECURITY_NAME_WORDS`, `_name_words`, `_words_match`); karar `_detect_security_relevance` (`:1829-`); çağıran `_build_function_header` (`:1665-`).
- **Güçlü etiket ("Handles …") yalnız çağrı kanıtıyla:** fonksiyonun çağrı grafiğindeki (kendi adresiyle) çağırdıkları arasında sınıfın gerçek API'si olmalı. Kripto API'leri `c_algorithm_id.CRYPTO_APIS` ile aynı kaynaktan (tek yer) + kitaplık aileleri (`EVP_`, `SHA256_`, `MD5_`, `HMAC_`, `CC_SHA`, `BCrypt`, Windows CryptoAPI'nin kripto işlevleri …); TLS (`SSL_`, `X509_`, `SecTrust` …); anahtar (`SecItem`, `SecKeychain`, `…PrivateKey…`); kimlik (`pam_*`, `getspnam`, `crypt`, `LogonUser` …); yetki (`setuid`, `setgroups`, `chroot`, `sandbox_init`, `AdjustTokenPrivileges` …); enjeksiyon (`WriteProcessMemory`, `CreateRemoteThread`, `SetWindowsHookEx*`, `MSHookFunction`, `mach_vm_write` …). API adları ayrı bir satıra yazılır: `@security_evidence calls EVP_DigestInit_ex, EVP_DigestUpdate` (`@security` satırının metni sınıf başına sabit kalır; P00 kapısı onu iddia anahtarı olarak sayıyor).
- **Ad kaynaklı etiket** yalnız ad ikilinin kendi simgesiyse (Ghidra'nın o adresteki adıyla aynı; Karadul'un önerdiği ad değil) ve adın **sözcüklerinden** biri sözlükte tam geçiyorsa; metin `By name only: <sınıf> (no call evidence)`. Belirsiz sözcükler (`key`, `token`, `hash`, `root`, `login`, `hook`, `patch`) sözlükte yok; kanca/enjeksiyon addan hiç verilmez.
- **Parametre etiketi** yalnız Ghidra'nın parametre adlarından (`By parameter name only: receives sensitive data (no call evidence)`); imza metni (Karadul'un yeniden adlandırdığı parametreler) kanıt değil.
